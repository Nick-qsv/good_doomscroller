# Twelve-book expansion - September 13, 2026

> **Superseded planning record:** This 26-book, 519-passage proposal was not the
> retained publication set after the later conservative rights review. It must
> not be used as a live inventory or release base. The current live library
> is documented in [`corpus/published/README.md`](../corpus/published/README.md).

This superseded proposal would have added **180 exact-source passages from 12
books**, fifteen per book, while preserving its 339-passage baseline. Its
proposed inventory contained **519 passages across 26 books**. Two assistants
independently reviewed every proposed passage for context, attribution,
complete thoughts, duplication and public selection rationale. No human
editorial signature is claimed.

Each bundle preserves the original source bytes, normalized text, exact sentence
spans, edition-specific Project Gutenberg US public-domain record, and separate
AI context. Darwin uses the Francis Darwin edited autobiography; Laozi uses
James Legge’s translation. Faraday uses the official EPUB to avoid a misleading
inherited preface heading. Individual edition notes record precise printed locations.
