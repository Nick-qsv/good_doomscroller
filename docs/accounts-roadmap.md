# Accounts: future scope

Reading, scrolling, and filtering by book or theme remain public, with no account
required. This release adds filters and remembers served quotes through the
existing anonymous browser cookie.

In a later release, require an account to like a quote or post a comment. Keep
the current reactions unchanged until the account system and migration are
ready; comments are not implemented in this release.

Accounts can support moderation and abuse controls, but registration alone does
not prevent bots. Plan verified registration, per-account and network request
limits, comment reporting and moderation, and account suspension together.
Choose the authentication service and define how existing anonymous reactions
are handled before implementing account-based interactions.
