# Meditations (George Long translation) — selection and context QC

This bundle preserves the unmodified [original Project Gutenberg file](https://www.gutenberg.org/cache/epub/15877/pg15877.txt) associated with the [official catalogue record](https://www.gutenberg.org/ebooks/15877). This expansion reused the already preserved original bytes; it did not retrieve a replacement file or create a new edition.

The preserved edition is George Long’s translation, Project Gutenberg eBook 15877, *Thoughts of Marcus Aurelius Antoninus*. The original catalogue assessment identifies this edition as public domain in the USA; this does not cover modern translations.

The text normalizer keeps the twelve printed books, introductory essays, footnotes, indexes, and Gutenberg notices in one source section labelled `Chapter 1`. That parser label does not mean printed Book I. The printed book/section references below identify the actual locations. All selected windows are in the main reflections, excluding introductory/editorial material, footnotes, and indexes. A quote can be a complete paragraph within a longer numbered reflection; it is not necessarily the whole numbered reflection. Leading section numbers are separate sentence tokens and are omitted from quotation windows.

The final set emphasizes attention, judgment, correction, practice, cooperation, and conduct. Long’s older wording is preserved. Context notes explain the surrounding argument without converting Marcus’s philosophical claims into guarantees about health or control over external events. The soldier-assault metaphor in VII.7 is marked for violence.

## Selection and separate explanation

Thirty nonoverlapping exact sentence windows were selected from deterministic candidates of 18–80 words and at most six sentences. The final quotations are 18–52 words (mean 31.8). The assistant read the candidate windows in their surrounding source, then separately read every final quote and its explanation for coherent boundaries, attribution, and faithful context. No quotation wording was rewritten.

Each passage has an `aiContext` explanation generated offline by the assistant: `generatedBy` is `AI`, and `generatedAt` is `2026-09-12T19:40:55.080706Z`. All explanations are trimmed, no more than 600 characters, and 18–45 words. These explanations are editorial interpretation, separate from the exact quote and its source receipt; verifying a quote does not prove an explanation. No human editorial review, external AI API selector call, authenticated publisher identity, or blockchain anchoring is claimed.

The existing selector contract remains `heuristic`. New curation reasons explicitly record assistant selection and contextual screening. 8 earlier exact passage IDs retain all prior quotation, provenance, and curation fields, with only the separate AI context added. 4 earlier ranges are omitted from this replacement bundle. Source metadata, book and edition IDs, original bytes, the entire normalized document, and normalization version are byte-for-byte or structurally unchanged from the backed-up twelve-passage bundle. Changed ranges receive the pipeline’s deterministic IDs; no old ID is repurposed for different text.
